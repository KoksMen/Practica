# Сборник практических работ на C# (C# Practice Repository)

## 📌 О проекте
Этот репозиторий представляет собой обширную коллекцию учебных проектов и практических (лабораторных) работ, выполненных в процессе изучения языка программирования C# и платформы .NET. 

Проект разбит на множество независимых модулей (от `PR1` до `PR33` и далее), каждый из которых посвящен определенной теме в программировании: от базовых алгоритмов до работы с базами данных и создания полноценного графического интерфейса.

## 🎯 Для чего нужен этот проект
Проект служит в качестве:
- Учебной базы для закрепления навыков программирования на C#.
- Демонстрации понимания принципов объектно-ориентированного программирования (ООП).
- Портфолио, показывающего прогресс в изучении различных технологий экосистемы .NET (Console, WinForms, WPF, базы данных).
- Шпаргалки с готовыми реализациями различных алгоритмов и паттернов проектирования.

## ⚙️ Как это работает и что умеет делать
Репозиторий состоит из единого решения (`Practica.sln`), которое объединяет множество мелких подпроектов. Каждый проект `PR...` решает конкретную задачу:
- **Консольные приложения:** реализация математических алгоритмов, работа со строками, массивами и структурами данных.
- **ООП и проектирование:** создание иерархий классов, использование интерфейсов, наследования и полиморфизма (включая UML-диаграммы классов `.cd`).
- **Desktop-приложения (Windows Forms):** создание оконных приложений с кнопками, формами, обработчиками событий.
- **Современный UI (WPF):** разработка интерфейсов с использованием разметки XAML (`App.xaml`, `MainWindow.xaml`).
- **Работа с базами данных:** подключение и взаимодействие с локальными базами данных (включая MS Access `.accdb`), использование ADO.NET и Entity Framework (`.edmx`) для маппинга данных (например, проекты с кулинарной книгой `CookingBook` или учетом пользователей).
- **Библиотеки классов:** выделение переиспользуемого кода в отдельные библиотеки (например, `ShopAuto`, `MyLib`).

Каждый проект можно сделать "запускаемым по умолчанию" в Visual Studio для тестирования его функционала.

## 🛠 Использованные технологии и инструменты
В ходе разработки проектов применялись следующие технологии:
* **Язык программирования:** C#
* **Платформа:** .NET Framework / .NET Core
* **Технологии графического интерфейса:** * Windows Forms (WinForms)
    * Windows Presentation Foundation (WPF) / XAML
* **Базы данных и ORM:** * Entity Framework
    * ADO.NET
    * Microsoft Access (OLE DB)
* **Среда разработки:** Microsoft Visual Studio (поддержка `.sln`, `.csproj`, генерация диаграмм классов `.cd`).
* **Дополнительно:** Работа с XML (LINQ to XML), файловым вводом/выводом, создание пользовательских контролов.
